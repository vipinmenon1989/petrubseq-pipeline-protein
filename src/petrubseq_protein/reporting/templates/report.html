{{ secn.strength }}. Perturbation strength

For every target gene that is also measured, the gene's own expression in cells carrying guides against it is compared with control cells: {{ strength.controls_described }}. Fold changes are computed on de-logged means; significance is a two-sample Kolmogorov-Smirnov test (one-sided Mann-Whitney beside it) with Benjamini-Hochberg correction across targets, per control arm. A target is called effective at FDR < {{ strength.fdr_alpha }} with a negative log2 fold change under {{ strength.primary_label }}{% if strength.fallback %} (the requested primary control was unavailable){% endif %}.

{{ secn.enrichment }}. Perturbation enrichment across clusters

Does losing a gene push cells into a particular transcriptional state? For every (target, cluster) pair a 2x2 table (target cells in / outside the cluster versus reference cells in / outside) is tested with Fisher's exact test{% if enr.stratified %}, stratified by {{ enr.stratify_by }} (Cochran-Mantel-Haenszel){% endif %}; both reference definitions ({{ enr.controls_described }}) are reported, and {{ enr.control_label }} drives the significance calls. Odds ratios carry a Haldane-Anscombe correction; pairs with few reference cells are flagged low-power; BH-FDR is applied within each arm.

{{ secn.enrichment }}.1 Is there any association at all?

Omnibus chi-square = {{ enr.chi2 }} on {{ enr.dof }} degrees of freedom, permutation p = {{ enr.p_perm }} ({{ enr.pct_small }}% of expected counts below 5, so the chi-square is a screen only). {{ enr.n_hits }} of {{ enr.n_tests }} target/cluster pairs are significant at FDR < {{ enr.fdr_alpha }}, involving {{ enr.n_targets_with_hits }} of {{ enr.n_targets }} targets across {{ enr.n_clusters }} clusters; {{ enr.n_low_power }} pairs are low-power.{% if enr.top_shift %} The largest composition shift is {{ enr.top_shift.target }} ({{ '%.1f' % enr.top_shift.composition_shift_pct }}% of its cells sit in different clusters than the reference).{% endif %}

{{ secn.ps }}. Per-cell perturbation response

The perturbation-strength test treats every cell carrying a guide as one group. This section scores each cell individually (Song et al. 2025, PS_python definition): for each target the expression signature of the perturbation is learned from target versus control cells and every cell is projected onto it, giving a score in [0, 1]. Combined with the target's own expression this classifies each perturbed cell as a successful knockdown, an escaper, a non-responder or low signal (cuts: score {{ ps.threshold }}, expression at the control {{ ps.cut_method }}). {{ ps.n_targets }} targets scored; median {{ ps.median_kd }}% of perturbed cells classed as successful knockdown, median {{ ps.median_escaper }}% escapers; best {{ ps.best }} ({{ ps.best_kd }}%), most escapers {{ ps.worst_escaper }} ({{ ps.worst_escaper_pct }}%).

{{ secn.lochness }}. lochNESS neighbourhood enrichment

For every cell and every perturbation, lochNESS = (share of the cell's {{ loch.k }} nearest neighbours carrying the perturbation) / (the perturbation's overall share) - 1: 0 is the background rate, positive means locally over-represented. It is continuous and cluster-free, so it also sees structure inside a cluster or across a boundary that the cluster test cannot. {{ loch.n_targets }} targets scored; {{ loch.n_positive }} have a mean score above {{ loch.cut }} in their own cells; strongest self-enrichment {{ loch.best }} ({{ loch.best_score }}).
